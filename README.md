## 一、先给结论：我最后选了什么，为什么

我的使用画像，先说清楚，方便你对号入座：

- 一个人用，不是团队，没有共享需求；
- 主力是 CLI 和 IDE 插件，读仓库、改代码、跑检查；网页版 ChatGPT 主要用来查资料；
- 每天用，但不是整天顶格跑；一周大概两三次集中写代码的高峰。

我从 Free 起步，第三周升到 Plus，之后一直没换档。中间替同事开过一次 Pro 100，看了一周他的用量页面之后又退回 Plus —— 他的问题不是档位不够，是每个任务都开得太大。

所以我的推荐很具体：

| 你的情况 | 我的建议 | 理由 |
| --- | --- | --- |
| 还在 Free / Go，想确认 Codex 能不能干活 | 先用 Free 跑两三个真实任务，别急着付钱 | 官方写明 Codex 覆盖 Free 和 Go，够你判断「值不值得」 |
| 每周有几次集中写代码 | **Plus（我最推荐的一档）** | 官方原话是「每周几次专注的编程会话」；我半年用它覆盖了 90% 场景 |
| Plus 天天触限、且真的卡住交付 | 先记录两层窗口，再考虑 Pro 100 | 我四次触限里只有一次接近「需要升档」 |
| 只是偶发不够用 | 买 credits，别升档 | credits 是按量补，升档是长期成本 |
| 要把模型接进 CI、脚本、自动化 | API 平台余额，与会员完全分开 | 开会员不会给你 API 额度 |

一句话：**Codex 没有单独会员，你充的钱其实是给 ChatGPT 账号升档。** 下面把这句拆开。

**我现在实际在用的方式**：账号始终是自己的，档位跑 [Plus宇宙](https://www.pluscosmo.com/) 的人民币直充，档位和当日价看他们的 [实时套餐页](https://www.pluscosmo.com/shop)。留下来是因为三点对我最要紧：全程不需要账号密码；订单在站内可查，付完就有订单号；续费前后都能拿订单号回账号里核对到期日。第一次跟着 [图文教程](https://www.pluscosmo.com/guide) 走，四步加起来不到十分钟。

## 二、Codex 充值到底充的是什么

我第一次搜「Codex 充值」时，以为存在一个「Codex 会员」可以买。没有这东西。

用 ChatGPT 账号登录 Codex 时，用的是**该账号 ChatGPT 方案自带的用量**。官方写明 Codex 覆盖各个 ChatGPT 方案，**包括 Free 和 Go**，只是各方案的用量和可用功能不同（来源：[Using Codex with your ChatGPT plan](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)）。

想通这一点之后，我把「Codex 充值」只理解成两种动作：

- 给自己的 ChatGPT 账号**开通或升级**付费方案（Go / Plus / Pro），拿到更多用量和功能；
- 已经是 Plus / Pro，只是阶段性不够用 → 买官方 **credits** 补量，不必换方案（来源：[Using Credits for Flexible Usage](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans)）。

顺带说一句我踩过的坑：我以为「充值」就等于「升级」，结果某次为了赶交付直接买了 credits，才发现自己那周本来就是 Plus 额度够用、只是任务喂太大。**先分清楚缺的是额度还是档位，能省一半钱。**

## 三、三种「Codex 充值」别混在一起

| 你的情况 | 实际要办的事 | 正确入口 |
| --- | --- | --- |
| 想更顺畅地用 Codex，账号还是 Free / Go | 开通或升级 Plus / Pro | 本文第三节、第八节 |
| 已是 Plus / Pro，只是某段时间不够用 | 官方 credits 补量 | ChatGPT「设置 → 用量」，或 Codex App「Usage & Billing」 |
| 用 API Key 调用 Codex / 模型 | API 平台余额 | [OpenAI 开发者平台](https://platform.openai.com/)，与 ChatGPT 账单完全分开 |

后两种，买会员解决不了：ChatGPT 订阅和 API 是两套独立账单（来源：[Managing billing for ChatGPT and the API platform](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)）；ChatGPT 内的 credits 也**不是** API credits。

## 四、档位与 Codex 权益（官方口径 + 我的选择逻辑）

| 档位 | 官方月费（美元） | Codex 相关权益（摘要） |
| --- | --- | --- |
| Free | $0 | 桌面 App 中以标准速度使用 GPT-6 Luna（逐步开放） |
| Go | $8（美国标价；部分地区为本地化定价） | 同上，定位「轻量编程任务」；不含 Codex Cloud |
| Plus | $20 | 网页、CLI、IDE 插件、iOS；自动代码审查、Slack 集成；可用 credits 补量 |
| Pro 100 / Pro 200 / Pro 500 | $100 / $200 / $500 | Plus 的全部权益加更高用量；**Ultrafast 只在 Pro 500 上有** |

来源：[Codex Pricing](https://learn.chatgpt.com/docs/pricing)、[About ChatGPT Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)、[Introducing ChatGPT Go](https://openai.com/index/introducing-chatgpt-go/)（Go 的 $8 为美国标价，官方注明部分市场本地化定价）。

**我是怎么定的档：** 我没有按「哪个最好」选，而是按「一周里有几次会被打断」选。Plus 的价位对应的是「每周几次专注会话」，正好是我的频率；Pro 的钱对应的是「每天都被打断」，那不是我的情况。所以 Pro 对我不是更好，是不必要。

关于 Pro 三档之间到底差多少，官方口径要看清：

- 官方只说 **「Pro 200 的用量多于 Pro 100，Pro 500 是三档中最高的」**，**没有**给出相对 Plus 的固定倍数。本文旧版写过「约 10x / 约 25x」，那是在官方页面核不到出处的数字，已删掉。
- 2026-10 官方更新：此前公告的 Pro 200 用量下调**已撤销**，Pro 200 重新开放新订阅；Pro 100 和 Pro 500 的 Work / Codex 用量翻倍；Plus 不变（来源：[About ChatGPT Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)）。
- 商品页上的「5X / 10X / 25X」属于商家自己的标注，**不是官方倍数**。我看到这种写法会直接跳过，因为它对不上任何官方页面。
- Go、Plus、Pro 都**只能按月订阅**，官方不支持年付或预付多个月（来源：[What is ChatGPT Go?](https://help.openai.com/en/articles/11989085-what-is-chatgpt-go)）。所以「年付立省」这类说法，要么是商家自己做的分期，要么就是话术。

## 五、用量机制：5 小时估算、每周上限、速度倍率

整理自官方 [Codex Pricing](https://learn.chatgpt.com/docs/pricing)，后面接的是我自己的观察：

- **Plus**：官方给的是「每 5 小时本地消息数」的**估算区间**，不是固定上限，例如 GPT-6.1 Sol 为 15–160 条、GPT-6 Luna 为 350–3,000 条。差这么多，是因为消耗取决于模型、上下文、推理、工具调用和缓存，而不是你发了几句话。
- **Pro**：官方写明 **Pro 目前没有 5 小时限制**（以后可能变）。
- **每周上限**：官方写明「可能还有每周上限」（Weekly limits may also apply），具体以账号内用量页为准。
- **速度模式**：相对同模型的标准模式，Fast 消耗会员自带用量 2.5 倍、消耗 credits 2 倍；Ultrafast（GPT-6 Astra / GPT-6.1 Sol，仅 Pro 500）消耗自带用量 8 倍、credits 6 倍。
- **共用额度**：本地消息和云端任务共用额度，Codex 与 ChatGPT Work 也共用同一份额度。这一点很容易忘 —— 我白天用 Work 写过东西，晚上 Codex 就觉得比平时吃紧。
- 查看剩余额度：CLI 里输入 `/status`，或打开用量页面。官方客服**不会**手动重置用量。

## 七、国内三条付款路径，我按顺序试了一遍

| 路径 | 能否用微信 / 支付宝 | 主要卡点 | 我自己的结果 |
| --- | --- | --- | --- |
| 官网直接订阅 | 否，通常需要国际卡 | 国内发卡常被拒；官方[支持地区列表](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)不含中国大陆与中国香港，在不支持地区使用可能导致账号被限制 | 试了两次，均被拒付，放弃 |

## 八、代充四步：我实际点了一遍

下面就是我在 [Plus宇宙](https://www.pluscosmo.com/) 走的那套流程（各处平台步骤大同小异，[套餐页](https://www.pluscosmo.com/shop) 会写明当期档位与价格）。每步后面是我当时的动作：

1. **选档**：在平台的套餐页核对档位、周期和当日价格。账号里已有订阅（官网 / Apple / Google Play）的，先确认归属和到期日，避免两份订阅同时计费。
   → 我先截了自己账号的订阅页，把「当前档位 + 到期日」存下来，验收时直接对比。
2. **提交 Session**：登录自己的 ChatGPT 账号，按结算页说明获取临时会话凭据（Session），只填在平台自己的 HTTPS 订单页。全程不需要密码、验证码和恢复码。
   → 这一步我第一次最紧张。后来想明白了判断标准：Session 只应该出现在平台自己的订单页里，任何要我发到聊天窗口的说法，直接换渠道。
   > Session 在有效期内可能具有账号访问权限，只填在平台自己的订单页，不要发到聊天窗口。完成后可在 ChatGPT 设置中退出所有设备，使该 Session 失效。
3. **付款**：用微信或支付宝在**平台生成的订单里**付款，保留订单号。不要按私聊要求转账到个人账户。
   → 付完立刻截了订单号和金额。不是为了维权，是为了验收时有时间点可对。
4. **验收**：处理完成后，用同一个账号登录官方 ChatGPT，在「设置 → 账户」核对方案名称和有效期，再到 Codex 里确认同一个账号已生效。**只认账号内显示，不凭订单状态判断。**
   → 我固定做两件事：账号页截图 + Codex 里跑一次 `/status`。两条都对上，才算这次交付结束。

## 九、避坑清单（都是我或身边人踩过的）

- 🚫 **要密码、短信 / 邮箱验证码、2FA 恢复码的「代充」** → 直接换渠道。这是唯一一条我不会给第二次机会的。
- 🚫 **只收 Session，但没有订单号、查不到进度** → 谨慎。我遇到过一次，全靠私聊口头承诺，退款拖了三天。
- 🚫 **要求转账到个人账户、绕过站内订单的「内部渠道」** → 不要付。
- 🚫 **会员还在有效期内，又重复买同档订阅** → 可能两处同时计费。我第一次续费时忘了关原渠道自动续费，白付了一个月。
- 🚫 **为了 API 额度去买会员** → 两套账单，互不抵扣。
- 🚫 **承诺「必不封号」「永久可用」「官方内部渠道」** → 当营销话术看，不要当保证。官方条款里没有任何第三方能替 OpenAI 背书。
- ✅ **验收只在官方账号内做**；售后时保留订单号和脱敏截图。

## 十、附录：Codex 相关的 10 类报错与排查顺序

这一节是我和身边几个用 Codex 的人实际撞过的。报错别急着重装或重复下单，按顺序对一下，多数能自己定位。

### 1. Codex 登进去额度是 0，但我明明开过会员

九成是**登录的账号不对**。Codex 用的是当前登录的 ChatGPT 账号的档位；你开会员的账号可能是另一个（常见于 Google 登录和邮箱密码登录被当成两个号）。先看 Codex 里显示的账号邮箱，再回 ChatGPT 账号页核对。

### 2. `/status` 显示的剩余额度和用量页面不一致

`/status` 读的是当前会话状态，用量页面读的是账号级窗口，两者刷新节奏不同。判断额度只认用量页面；`/status` 更适合确认「我到底用哪个账号登录」。

### 3. 提示已达上限，但页面没给重置时间

大概率撞的是**每周窗口**，不是 5 小时窗口。5 小时窗口一般会给出恢复时间；没有时间点的，先按每周处理，别急着买 credits。

### 4. 买了 credits，余额显示是负数

正常现象。任务开始时余额为正，跑到一半被并发任务吃穿，就会出现负数；后续买的 credits 会先补负值部分。它不代表扣错钱。

### 5. credits 买了，Codex 里却用不了

先确认两件事：这个 credits 是买在**当前登录账号**上；以及这项功能是否在 credits 的可用范围内。credits 覆盖 Codex、ChatGPT Work、ChatGPT for Word / Excel / PowerPoint 等符合条件的功能，不是全部功能。

### 6. 换成 API Key 登录后，云端功能不见了

这是设计如此：API Key 登录不支持云端功能（如 GitHub 代码审查、Slack 集成）。要这些功能，就用 ChatGPT 账号登录。

### 7. 团队工作区里看不到自己的用量

工作区和账号不是一回事。先确认当前是个人工作区还是组织工作区，再去看对应位置的用量与账单。

### 8. 升档成功了，Codex 里还显示旧档位

退出所有设备后重新登录，或者重开一个会话。额度与档位是账号级的，但客户端会缓存上次的会话状态。

### 9. 额度掉得比平时快很多

先看三件事：是不是开着 Fast / Ultrafast（Fast 吃 2.5 倍、Ultrafast 吃 8 倍）；是不是同时有云端任务在跑（两者共用额度）；是不是白天用 Work 用掉了一部分。

### 10. 订阅到期后 Codex 立刻掉档

会员到期就没有对应档位权益，Codex 会退回 Free 的可用范围。续费前后各看一眼账号页的到期日，比事后查原因省事。

## 十一、常见问题 FAQ

**Q1：Codex 充值和 ChatGPT Plus 充值是同一件事吗？**
对用 ChatGPT 账号登录 Codex 的人，基本是同一件事：Codex 用量跟着 ChatGPT 方案走。例外是用 API Key 的人，那属于 API 账单。

**Q2：Free 能不能用 Codex？**
可以。官方写明 Codex 覆盖 Free 和 Go，但用量和功能有限，Codex Cloud 不含在 Free / Go 里（来源：[Using Codex with your ChatGPT plan](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)）。我当初就是用 Free 跑了两个小任务，确认工具合我的工作方式，才决定升档。

**Q3：Plus 不够用，一定要升 Pro 吗？**
不一定。Plus / Pro 触限后可以直接买 credits，不用换方案。只有同一层限制长期影响交付，才值得升档。我自己到现在还是 Plus。

**Q4：先买 Plus 还是先买 credits？**
